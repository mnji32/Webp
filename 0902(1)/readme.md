## 09월 02일 수업내용

### 1. 웹(Web)의 기본 구조 및 동작
* **인터넷 vs 웹**: 인터넷은 전 세계 컴퓨터 네트워크 인프라이며, 웹(WWW)은 인터넷 상에서 정보를 공유하는 서비스입니다.
* **웹 동작 방식**: 웹 브라우저(클라이언트)가 웹 서버에 **요청(Request)**하면, 서버가 해당 웹 문서(HTML 등)를 **응답(Response)**하여 화면에 출력합니다.
* **URL 구조**: `프로토콜://서버주소:포트/경로/파일명` (예: `http://www.site.com:80/dir/page.html`)
* **HTTP 프로토콜**: 웹 문서 송수신을 위한 규약으로, 응답 후 접속을 끊는 비연결성(Stateless) 특징을 가집니다.

---

### 2. 웹 페이지의 3대 구성 요소
웹 개발은 **구조, 디자인, 동작**을 분리하여 개발합니다.

| 구분 | 역할 | 주요 언어 및 태그 |
| :--- | :--- | :--- |
| **구조 (Structure)** | 웹 문서의 뼈대와 내용 작성 | **HTML** (`<h3>`, `<p>`, `<img>` 등) |
| **디자인 (Presentation)** | 레이아웃, 색상, 폰트 등 시각적 스타일 | **CSS** (`color`, `font-size`, `margin` 등) |
| **동작 (Behavior)** | 마우스 클릭, 호버 등 동적 로직 처리 | **JavaScript** (`function`, `addEventListener` 등) |

---

### 3. HTML5의 등장 배경 및 특징
* **등장 배경**: ActiveX, Flash 등 비표준 플러그인을 제거하고, 다양한 모바일 기기 및 브라우저에서 동일하게 동작하는 범용 웹 표준 제정
* **주요 특징**
  * 플러그인 없이 `<audio>`, `<video>` 태그만으로 멀티미디어 재생
  * `<canvas>`/`SVG`를 이용한 2D/3D 그래픽 표현
  * Web Storage, Geolocation, WebSocket 등 웹 애플리케이션 개발을 위한 자바스크립트 API 제공

---

### 4. 웹 개발 환경 및 규칙
* **파일 확장자**: `.html` 또는 `.htm`
* **한글 인코딩**: 한글 깨짐 방지를 위해 문서 헤더에 `<meta charset="UTF-8">` 필수 지정
* **디버깅**: 브라우저 단축키 **`F12`**(개발자 도구)를 이용하여 HTML/CSS 요소 검사 및 자바스크립트 디버깅 수행
