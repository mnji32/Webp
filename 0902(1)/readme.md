## 1. 웹(Web)의 기본 개념 및 구조
### 1) 인터넷(Internet) vs 웹(Web)
* **인터넷 (Internet)**: 1969년 미 국방성에서 시작된 전 세계 컴퓨터를 연결하는 네트워크 인프라
* **웹 (World Wide Web, WWW)**: 1989년 팀 버너스리(Tim Berners-Lee)가 제안한 인터넷 기반의 정보 공유 네트워크 시스템

### 2) 웹의 작동 구조
웹은 **웹 서버(Web Server)**와 **웹 클라이언트(Web Client)** 간의 요청-응답(Request-Response) 모델로 동작
| 구분 | 역할 및 특징 | 예시 |
| :--- | :--- | :--- |
| **웹 서버** | • 웹 사이트 및 데이터(HTML, 이미지, 동영상 등) 관리<br>• 클라이언트의 요청에 따라 웹 문서 전송 | Google, Naver, Amazon 서버 |
| **웹 클라이언트** | • 사용자 인터페이스(UI) 담당<br>• 웹 서버에 문서를 요청하고 받아 화면에 출력 | 웹 브라우저 (Chrome, Edge, Safari 등) |

---

## 2. 웹 문서 vs 전자 문서 & URL/HTTP
### 1) 웹 문서와 전자 문서의 차이점
| 항목 | 전자 문서 (Word, HWP 등) | 웹 문서 (HTML) |
| :--- | :--- | :--- |
| **파일 구조** | 단일 파일 내에 텍스트, 이미지 등을 직접 저장 | 페이지 단위(`.html`) 분할 저장 |
| **미디어 연결** | 문서 내부 포함 | 이미지, 동영상 등은 별도 파일로 연결 |
| **탐색 방식** | 작성자가 정한 순서대로 읽음 | **하이퍼링크(Hyperlink)**를 통한 사용자 중심 내비게이션 |

### 2) URL (Uniform Resource Locator) 구조
웹 페이지의 인터넷 주소 체계입니다.
* **프로토콜**: 통신 규약 (`http`, `https`, `ftp` 등)
* **서버 주소**: 웹 페이지가 존재하는 컴퓨터의 IP/도메인
* **포트 번호**: 서비스 식별 번호 (HTTP 기본: `80`, HTTPS 기본: `443`)

### 3) HTTP (HyperText Transfer Protocol) 통신
1. 클라이언트가 웹 서버에 **연결 요청**
2. 웹 서버 접속 수락 후, **HTML 문서 요청**
3. 웹 서버가 요청받은 **문서 전송** 후 **접속 종료** (비연결성 특징으로 서버 부하 최소화)
4. 웹 브라우저가 문서를 **해독(파싱) 및 출력**

## 3. 웹 페이지의 3대 구성 요소
웹 페이지는 **구조, 디자인, 동작**을 분리하여 개발

* **HTML (HyperText Markup Language)**: 태그를 통해 문서의 구조 및 내용을 정의
* **CSS (Cascading Style Sheets)**: 색상, 폰트, 레이아웃 등 웹 페이지의 시각적 스타일 지정
* **JavaScript**: 마우스 이벤트 처리, 애니메이션, DOM 조작 등 사용자 인터페이스 및 상호작용 구현

---

## 4. HTML5의 등장 배경 및 주요 특징
### 1) HTML5 출현 배경
* **비표준 플러그인 남발**: ActiveX, Flash 등 브라우저별 비호환성 문제 해결
* **모바일 시대의 도래**: 스마트폰, 태블릿 등 다양한 기기 환경 지원 필요
* **표준화**: W3C 및 WHATWG를 중심의 새로운 범용 웹 표준 제정

### 2) HTML5의 핵심 변화
* 플러그인(ActiveX/Flash) 없이 **오디오·비디오 재생** 및 **게임/그래픽 처리** 가능
* **웹 플랫폼 확장**: Simple 문서 작성을 넘어 웹 애플리케이션 개발을 위한 자바스크립트 API 표준 제공
* **주요 기능 API**: Web Form, Canvas/SVG, Web Storage, Geolocation, Web Worker, WebSocket 등

---

## 5. HTML5 작성 및 개발 환경
### 1) 기본 작성 규칙
* **텍스트 에디터**: VS Code, Sublime Text, Atom 등 다양한 에디터 사용 가능.
* **인코딩 설정**: 한글 깨짐 방지를 위해 파일 저장은 반드시 **`UTF-8`** 문자셋 지정.
* **확장자**: `.html` 또는 `.htm`

### 2) 디버깅 및 개발자 도구 (Developer Tools)
* 웹 브라우저(Chrome 등)에서 **`F12`** 키 또는 `우클릭 -> 검사(Inspect)`를 통해 열기.
* HTML/CSS 요소 실시간 확인 및 변경, 자바스크립트 디버깅, 네트워크 상태 모니터링 가능.
