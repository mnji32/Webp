## 09월 16일 수업 내용

### 1. HTML5 폼(Form)의 기본 개념 및 동작
* **폼(Form)**: 사용자로부터 입력을 받아 서버로 전송하는 웹 페이지의 입력 양식
* **`<form>` 주요 속성**
  * `action`: 입력 데이터를 처리할 서버 프로그램(URL) 지정
  * `method`: 데이터 전송 방식 지정 (`GET` - URL에 전송 데이터 노출 / `POST` - 요청 본문에 숨겨서 전송)
  * `name`: 폼을 식별하는 이름

---

### 2. 기본 입력 폼 태그 및 버튼
* **텍스트 입력**
  * `<input type="text">`: 한 줄 텍스트 입력
  * `<input type="password">`: 마스킹(`*`) 처리되는 암호 입력
  * `<textarea>`: 여러 줄의 텍스트 입력 (`rows`, `cols` 속성)
  * `<datalist>`: `<input type="text">`에 자동완성/선택목록 힌트 제공
* **버튼 요소**:
  * `submit`: 폼 데이터를 서버로 전송
  * `reset`: 입력된 모든 데이터 초기화
  * `button`: 자바스크립트로 클릭 이벤트를 처리할 단순 버튼

---

### 3. 선택형 요소 & `<label>` 태그
| 구분 | 태그 및 속성 | 특징 |
| :--- | :--- | :--- |
| **체크박스** | `<input type="checkbox">` | 여러 항목을 **중복 선택** 가능 |
| **라디오 버튼** | `<input type="radio">` | 같은 `name`을 가진 그룹 중 **단 하나만 선택** |
| **드롭다운** | `<select>`, `<option>` | 목록에서 하나를 선택하는 콤보박스 (`selected`로 기본값 지정) |

* **`<label>` 태그의 역할**:
  * 폼 요소에 **텍스트 캡션**을 연결함
  * 캡션 텍스트나 이미지를 클릭해도 해당 입력 요소가 선택되어 **사용자 편의성(UX)** 증가

---

### 4. HTML5에 추가된 다양한 `<input>` 타입 및 기능
* **숫자 조절**
  * `<input type="number">`: 스핀 버튼으로 정교한 숫자 입력 (`min`, `max`, `step`)
  * `<input type="range">`: 슬라이드 바로 대략적인 범위 값 입력
* **날짜 및 시간 입력**
  * `<input type="date|time|datetime-local|month|week">`: 달력 및 시간 선택 팝업 제공
* **형식 검사 & 텍스트 힌트**
  * `email`, `url`, `tel`, `search`: 제출 시 브라우저가 자동으로 데이터 형식 검증
  * `placeholder` 속성: 입력창 내에 데이터 작성 힌트(가이드) 문구 표시
* **기타 편리한 폼 컨트롤**
  * `<input type="color">`: 컬러 다이얼로그를 통해 색상 선택
* **그룹핑 태그**
  * `<fieldset>`: 관련 입력 요소들을 하나의 상자로 테두리 묶기
  * `<legend>`: `<fieldset>` 박스에 제목 표시
