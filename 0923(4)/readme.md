### 1. CSS3 스타일 시트 개념 및 작성 방법
* **CSS3 (Cascading Style Sheet)**: HTML 문서의 색상, 폰트, 레이아웃 등 외관을 제어하는 언어
* **기본 문법**: `셀렉터 { 프로퍼티: 값; }` 구조
* **스타일 시트 적용 방식 3가지**:
  1. **내부 스타일 시트**: `<head>` 태그 안에 `<style>` 태그로 작성
  2. **인라인 스타일**: HTML 태그의 `style` 속성에 직접 작성
  3. **외부 스타일 시트**: 별도의 `.css` 파일로 저장 후 `<link>` 태그나 `@import`로 불러오기

---

### 2. 셀렉터 (Selector)의 종류
원하는 HTML 요소를 선택하여 스타일을 적용하기 위한 구문

| 셀렉터 종류 | 작성 예시 | 설명 |
| :--- | :--- | :--- |
| **태그 이름 셀렉터** | `h3, p` | 지정한 HTML 태그 전체에 스타일 적용 |
| **클래스 셀렉터** | `.warning` | `class="warning"` 속성을 가진 모든 요소에 적용 |
| **id 셀렉터** | `#list` | `id="list"` 속성을 가진 단 하나의 요소에 적용 |
| **자식 / 자손 셀렉터** | `div > p` / `ul strong` | 특정 태그 내부의 자식 요소 또는 자손 요소를 선택 |
| **가상 클래스 셀렉터** | `li:hover`, `a:visited` | 마우스 호버, 방문 여부 등 특정 상태나 행동 시 적용 |

---

### 3. 스타일 상속, 색상 및 폰트 표현

* **스타일 상속 (Inheritance)**: 부모 태그에 적용된 스타일 속성은 자식 태그에 자동으로 상속됨 (예: `<p>`의 글자 색상은 내부 `<em>` 태그에도 적용)
* **색상 표현 방식 (3가지)**:
  * 16진수 코드 (`#8A2BE2`)
  * RGB 10진수 (`rgb(138, 43, 226)`)
  * 색상 이름 (`blueviolet`)
* **폰트 지정**: `font-family`(글꼴), `font-size`(크기: `px`, `em`, `pt`), `font-weight`(굵기), `font-style`(기울임) 등

---

### 4. 박스 모델 (Box Model)
모든 HTML 요소는 사각형 박스 형태의 영역으로 구성

* **콘텐츠 (Content)**: 텍스트나 이미지가 들어가는 실제 영역
* **패딩 (Padding)**: 콘텐츠와 테두리 사이의 **내부 여백**
* **테두리 (Border)**: 패딩 바깥쪽을 둘러싸는 **선**
* **마진 (Margin)**: 테두리 바깥쪽의 **외부 여백** (이웃한 박스와의 간격)
* **기타 효과**: `box-shadow` (그림자 효과), `border-radius` (둥근 테두리 처리) 등
