## 09월 09일 수업내용

### 1. HTML5 문서의 기본 구조 및 텍스트 태그
* **기본 구조**: `<!DOCTYPE html>`, `<html>`, `<head>`, `<body>` 태그로 구성
* **제목 & 단락**
  * `<h1>` ~ `<h6>`: 문단 제목 표시 (숫자가 작을수록 큰 글씨)
  * `<p>`: 단락 나누기
  * `<br>`: 줄 바꿈 (단독 태그)
  * `<hr>`: 수평선 긋기 (단독 태그)
  * `<pre>`: 개발자가 작성한 띄어쓰기 및 줄바꿈 포맷 그대로 출력
* **특수 문자(엔터티 표현)**: `<` => `&lt;` / `>` => `&gt;` / `&` => `&amp;` / 공백 => `&nbsp;` 등

---

### 2. 블록(Block) 태그 vs 인라인(Inline) 태그

| 구분 | 특징 | 대표적인 태그 |
| :--- | :--- | :--- |
| **블록 태그** | • 항상 새 줄에서 시작하며 라인 전체를 독점 사용<br>• 구조를 잡을 때 주로 사용 | `<div>`, `<p>`, `<h1>`~`<h6>`, `<ul>`, `<ol>`, `<table>` 등 |
| **인라인 태그** | • 줄 바꿈 없이 텍스트 흐름 안에서 필요한 만큼만 공간 차지<br>• 특정 부분 스타일 적용 시 사용 | `<span>`, `<a>`, `<img>`, `<strong>`, `<em>`, `<mark>` 등 |

---

### 3. 리스트(List) & 표(Table) 작성

* **리스트(List)**:
  * `<ol>`: 순서가 있는 리스트 (1, 2, 3...)
  * `<ul>`: 순서가 없는 리스트 (불릿 기호)
  * `<dl>`, `<dt>`, `<dd>`: 용어 정의 형태의 리스트

* **표(Table)**:
  * `<table>`: 표 전체를 감싸는 컨테이너
  * `<caption>`: 표의 제목
  * `<thead>`, `<tbody>`, `<tfoot>`: 표의 구조적 구획 분할
  * `<tr>`: 행(Row) 생성 / `<th>`: 열 제목 셀 / `<td>`: 일반 데이터 셀

---

### 4. 하이퍼링크, 이미지, 미디어 및 프레임

* **하이퍼링크 (`<a>`)**:
  * `href`: 이동할 URL 또는 파일 경로 지정
  * `target="_blank"`: 새 탭에서 링크 열기
  * `download`: 파일 직접 다운로드 기능 제공
* **이미지 (`<img>`)**: `src`(경로), `alt`(대체 텍스트), `width`/`height`(크기) 속성 활용
* **인라인 프레임 (`<iframe>`)**: 웹 페이지 내에 다른 웹 페이지를 내장
* **오디오 & 비디오 (`<audio>`, `<video>`)**:
  * HTML5 표준 태그로 별도 플러그인 없이 실행
  * `controls`(제어창 표시), `autoplay`(자동 재생), `loop`(반복 재생) 속성 제공
