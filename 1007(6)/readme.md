## 10월 07일 수업내용

### 1. 자바스크립트 개요 및 역할
* **개념**: 1995년 넷스케이프에서 개발된 스크립트 언어로, HTML 문서 내에 내장되어 웹 페이지에 동적인 생명력을 불어넣음
* **주요 역할**:
  * 사용자 입력 처리 및 계산 (마우스/키보드 이벤트 핸들링)
  * HTML 태그의 콘텐츠, 속성, CSS 스타일을 동적으로 변경
  * 브라우저 제어 (새 창 열기/닫기, 히스토리 제어)
  * 서버와의 통신 및 웹 애플리케이션 기능(캔버스, 저장소 등) 제공

---

### 인터프리터(Interpreter) vs 컴파일러(Compiler)

자바스크립트는 소스 코드를 한 줄씩 해석하며 바로 실행하는 **인터프리터 언어**

| 구분 | 인터프리터 (Interpreter) | 컴파일러 (Compiler) |
| :--- | :--- | :--- |
| **실행 방식** | 소스 코드를 한 줄씩 읽어가며 즉시 실행 | 전체 소스 코드를 한 번에 기계어로 번역 후 실행 |
| **번역 시점** | 프로그램 **실행 중**에 동시 번역 | 프로그램 **실행 전**에 사전 번역 (Compile step) |
| **실행 속도** | 초기 실행 속도는 빠르나, 전체 실행은 상대적으로 큼 | 초기 번역 시간은 걸리지만, 실행 속도가 매우 빠름 |
| **목적 파일** | 별도의 실행 파일(`.exe` 등)을 생성하지 않음 | 기계어로 된 목적 파일(`.exe`, `.class` 등) 생성 |
| **대표 언어** | **JavaScript**, Python, Ruby 등 | C, C++, Java, Go 등 |

### 2. 자바스크립트 코드 작성 위치 4가지
1. **HTML 태그의 이벤트 리스너 속성**: `<img onclick="this.src='apple.png'">`
2. **`<script>` 태그 내부**: `<head>`나 `<body>` 내 어디든 삽입 가능
3. **외부 자바스크립트 파일(`.js`)**: `<script src="lib.js"></script>`로 불러와 재사용
4. **URL 위치**: `<a href="javascript:alert('안녕')">`

---

### 3. 입출력 및 다이얼로그(Dialog) 함수
* **출력 방식**: `document.write()`를 사용하여 웹 페이지 본문에 HTML 콘텐츠 직접 출력
* **입력 & 알림 다이얼로그**:
  * `alert("메시지")`: 경고창 출력 (확인 버튼)
  * `confirm("질문")`: 확인/취소 선택창 (`true`/`false` 리턴)
  * `prompt("메시지", "기본값")`: 사용자로부터 텍스트 입력을 받아 리턴

---

### 4. 핵심 문법 및 주요 전역 함수
* **변수 선언**: `let`(재할당 가능 변수), `const`(상수)
* **제어문**: `if-else`, `switch`, `for`, `while`, `break`, `continue` 등 기존 C언어 문법 구조 차용
* **주요 전역 함수**:
  * `eval(exp)`: 전달된 자바스크립트 수식/문자열을 연산하여 결과 리턴
  * `parseInt(str)` / `parseFloat(str)`: 문자열을 정수 또는 실수로 변환
  * `isNaN(value)`: 값이 숫자가 아닌지 판단 (`NaN`: Not a Number)
